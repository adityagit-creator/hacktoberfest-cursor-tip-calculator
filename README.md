# Tip Calculator

A beginner-friendly tip calculator built with HTML, CSS, and JavaScript. Enter a bill, pick a tip (10%, 15%, 20%, or custom), split it between people, and see the tip, total, and per-person amount update as you type. Includes dark mode and input validation.

## Run locally

You only need a browser. No install or build step.

1. Open the project folder.
2. Double-click `index.html`, or right-click it and open it in Chrome, Edge, or Firefox.

Optional: serve the folder so you can use a local URL.

```bash
# Python 3
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
